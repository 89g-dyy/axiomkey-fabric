# Licensing

AxiomKey Fabric is released as open source using a multi-license model. Every contribution must be compatible with the license that applies to the part of the repository it touches.

| Scope | License | File |
|---|---|---|
| Firmware, software, and tooling | [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0) | [`LICENSE`](LICENSE) |
| Hardware designs (schematics, PCB layout, 3D-print files, hardware documentation) | [CERN Open Hardware Licence v2 — Strongly Reciprocal](https://ohwr.org/cern_ohl_s_v2.txt) | [`LICENSE-HARDWARE`](LICENSE-HARDWARE) |
| General documentation | [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) | [`LICENSE-DOCS`](LICENSE-DOCS) |

## Important notes

1. **Software** (`FW/`, `Tools/`, workflows, and scripts) is licensed under Apache-2.0. You may use, modify, and distribute it, including in commercial products, provided you keep the attribution notices.
2. **Hardware** (design files under `HW/`, `3D_Print/`, and hardware documentation inside project knowledge bases) is licensed under CERN-OHL-S-2.0. If you modify the design files and distribute them or the products made from them, your modifications must be released under the same license and the license must be conveyed with the product.
3. **Documentation** is licensed under CC-BY-4.0. You may share and adapt it with attribution.
4. When contributing, you agree that your contribution will be licensed under the terms that apply to the corresponding part of the repository.

If you are unsure which license applies to a file, check the folder-level README or the header of the file itself.
