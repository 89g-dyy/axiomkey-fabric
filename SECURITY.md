# Security and Safety Reporting

This repository contains hardware and firmware design material. Safety issues include electrical overstress, reverse current, over-temperature, battery hazards, unsafe connector behavior, and firmware behavior that can enable power rails incorrectly.

Do not publish a detailed exploit or hazardous reproduction procedure in a public issue. Contact the project owner privately and include:

- affected board and revision;
- affected firmware version or commit;
- power source and test conditions;
- observed behavior and potential consequence;
- proposed mitigation, if known.

No response-time commitment has been established yet.
