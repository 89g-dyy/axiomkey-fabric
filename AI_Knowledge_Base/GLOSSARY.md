# Glossary

| Term | Meaning |
| --- | --- |
| AxiomKey Fabric | Modular development platform using custom MKEY and BKEY interfaces |
| Baseboard | Main board containing the ESP32-S3 management controller, gateway, insertion detection, power, USB Hub, logging, protection, and module routing |
| USB role switch | Mutually exclusive routing of MKEY USB to the Hub in Device mode or USB-A in Host mode |
| MKEY | Key M core module carrying an MCU, SoC, or FPGA |
| BKEY | Key B replaceable sensor module |
| `3V3_B` | Main BKEY 3.3 V power domain on pins 70, 72, and 74 |
| `3V3_LDO0` | Independent low-noise BKEY 3.3 V supply on pins 2 and 4 |
| `VIO_B` | BKEY digital interface reference generated by LDO1 on pins 20 and 22 |
| `VIO_CFG` | BKEY voltage strap: GND requests 3.3 V; high impedance requests 1.8 V |
| `PRESENT#` | Active-low board-presence indication |
| LANE0-3 | Four reusable differential-pair resources; not a statement that the connector implements PCIe x4 |
| IO_AUX | Low-speed auxiliary GPIO, normally through an optional baseboard expander |
| Source of truth | File whose definition takes precedence when documentation conflicts |
