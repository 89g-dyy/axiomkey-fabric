# External Sources

Store only references that the project has permission to redistribute. Prefer a Markdown index containing manufacturer, document title, revision, publication date, and official URL over copying third-party PDFs into the repository.

For each design-critical value, record:

- component and manufacturer;
- datasheet or application-note revision;
- page, table, or section;
- value or requirement derived from the source;
- date reviewed.

Do not treat forum posts, AI output, or distributor summaries as authoritative electrical specifications.
